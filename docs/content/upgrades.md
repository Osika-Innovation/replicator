# The upgrade loop

Design the machine and the route by which it improves together. The objective is the smallest credible seed platform that can expand its useful manufacturing capabilities with progressively less human work.

## One enduring platform

Keep the frame, datums, utility connections, calibration tools and software interfaces reusable. Replace or add modules as capabilities improve. Several workshop machines may share the same modules and twin.

Purchased transducers, electronics, optics and outsourced masters are valid seed inputs. Record their role and the condition under which in-house fabrication would reduce total effort.

## A complete upgrade record

Every upgrade identifies:

1. The limiting capability and proposed benefit.
2. The part or process that changes it.
3. Required materials, fabrication precision and metrology.
4. All prerequisites and external steps.
5. Predicted benefit and the observations that would establish it.
6. Human effort, cost, machine time and likely rework.
7. Compatibility with the enduring platform.

The first self-made upgrade passes only after manufacture, inspection, installation and a measured improvement over the previous configuration.

## Search from both ends

The end-state architecture asks which functions can share a structure, which materials simplify the machine and which modules it can reproduce.

The near-term programme asks what can be made with today's seed capabilities. A dependency graph joins the two. Each candidate includes its manufacturing recipe and the capability it unlocks.

Avoid circular bootstrap plans. If an optical module requires a surface finish unavailable to the seed, name the external finishing route or the intermediate upgrade that supplies it.

## Measure independence by dependencies

Track external parts, processes, materials, metrology and human assembly separately. A high self-made mass fraction can coexist with a critical external dependency.

Self-copying and self-improvement are different milestones. Improvement requires design search, reliable fabrication, measurement and selection. Resolution, throughput, material range, energy and reliability form tradeoffs rather than one universal final shape.

## The autonomous campaign

Find one robust path from available seed components to an inspected part that improves this platform. Produce the geometry, process sequence, tolerance budget, inspection plan, expected benefit and smallest decisive measurement.

Report decisions changed, candidates retained or rejected and the next uncertainty. A completed batch is useful when it changes the engineering decision.
